# 💫 SIMPLE 
- Passé : **ed** 
- Présent : **s** (il/elle)
- Futur : **will**

# 🔄 CONTINUOUS = **be** + **ing**
- Passé : **was/were** + ing
- Présent : **am/is/are** + ing
- Futur : **will be** + ing

# ⛓️ PERFECT = **have** + **participe passé**
- Passé : **had** + pp
- Présent : **have/has** + pp
- Futur : **will have** + pp

# ⏳ PERFECT CONTINUOUS = **have** + **been** + **ing**
- Passé : **had been** + ing
- Présent : **have/has been** + ing  
- Futur : **will have been** + ing

# En gros :
- Simple = action normale
- Continuous = ajouter **ing**
- Perfect = ajouter **have** + **participe passé**
- Perfect Continuous = combiner les deux
